# Joker-Icons

Hier die drei Icon-Bilder ablegen (PNG mit transparentem Hintergrund empfohlen, quadratisch,
z.B. 128×128px):

- `veto.png`
- `wondertrade.png`
- `wechsel.png`

Fehlt eine Datei (oder lädt sie nicht), zeigt die App automatisch ein Emoji-Platzhalter-Icon an
— das UI funktioniert also auch ohne eigene Icons.
